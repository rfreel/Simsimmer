# Project Intent

## Mission
Simsimmer is a simulation-first research and software-engineering system whose durable purpose is to make future search cheaper, safer, and more capable through verified reusable learning.

## Current objective
Build a long-lived control plane that enforces:

`SIMULATE → SELECT → GENERATE → EXECUTE → VERIFY → ACCRETE → RELATE → GENERALIZE → COMPILE → TRANSFER → REDISCOVER → ABLATE → RE-DERIVE → COMPRESS → SEARCH FARTHER`.

## Problem
Normal agentic coding consumes large amounts of reasoning and execution but often retains only the final patch. Failures, counterexamples, routing lessons, verification structure, and reusable procedures are lost or left in chat history.

## Desired state
Each unit of work should leave behind at least one of:
- verified improvement;
- reusable operator/workflow;
- learned failure boundary or counterexample;
- stronger verifier/fixture;
- smaller active basis with equivalent reachability;
- explicit unresolved residual.

## Scope
In scope now: repository control plane, immutable simulation, experiment contracts, local execution adapters, verification, task/agent coordination, trace retention/compilation, and tool adapters.

Out of scope until separately promoted: weakening evaluator/holdout gates, autonomous deployment, secrets management beyond integration contracts, arbitrary self-modifying trusted code, and claims of global optimality/saturation.

## Authority
Human intent and explicit repository contracts are authoritative. Candidate agents, simulations, external tools, generated reports, and learned policies are advisory until accepted through the repository promotion process.

## Success criterion
The system demonstrates increasing verified capability or decreasing expected future work per unit compute while preserving rollback, provenance, and independent verification.

## Stopping rule
A finite experiment stops when its frozen budget or stopping condition is reached. Open-ended research stops only for an explicit resource boundary, saturation criterion, or human decision; "looks good" is not a stopping rule.
