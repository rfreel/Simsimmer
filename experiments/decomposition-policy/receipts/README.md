# Decomposition receipts

- `BEADS_RECEIPT.json` is preserved in repository form and binds the selected graph to the exact generated `BEADS.jsonl` and `BEADS_TODO.md` hashes.
- `DECOMPOSE_SIM_RECEIPT.json` is a normalized semantic repository copy used by the verifier. `SOURCE_MANIFEST.json` preserves the exact Library artifact identity and SHA-256 of the original receipt.

Do not conflate semantic equivalence with byte identity.
