# decompose-task-space

Canonical decomposition work for Simsimmer lives here. This subsystem is not a parallel authority: it is subordinate to `PROJECT_INTENT.md`, `control/**`, and `AGENTS.md`.

The decomposition model keeps these typed layers distinct:
- task containment;
- execution dependency;
- frame/representation;
- operator/transformation;
- witness/delta/evidence.

Cross-cutting axes such as telos, time, epistemics, resources, risk, provenance, and verification remain orthogonal unless an explicit relation is evidenced.

`spec/` contains the domain-agnostic Specification Distinction Basis and the protocol for extending it without simply appending domain vocabulary.
