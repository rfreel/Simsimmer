# Specification Distinction Basis

This is the canonical specification ontology for `decompose-task-space/`, subject to the repository authority hierarchy. It exists to make decision-relevant distinctions explicit before implementation.

Files:
- `SPEC_DISTINCTION_BASIS.md` — normative generic axes.
- `EXTENSION_PROTOCOL.md` — specialized-domain admission and saturation rules.
- `data/distinctions.json` — machine-readable basis.
- `data/relations.json` — allowed relation vocabulary.
- `data/residuals.json` — unresolved specialization gaps.
- `witnesses/` — minimal discriminating witnesses.
- `tests/` — ablation/category-error checks.
- `simulate_spec_basis.py` — low-discrepancy probe scheduler.

No checklist item becomes a primitive by naming it. Retention requires ablation evidence; specialized additions require repeated non-derivable witnesses.
